# Vstore site

Статический сайт каталога цифровых товаров без сборщика и серверной части.

## Локальный запуск

```bash
python3 -m http.server 8000
```

После запуска сайт доступен по адресу `http://localhost:8000/`.

## Структура

- `index.html` — главная страница и популярные товары.
- `catalog.html` — каталог с поиском и фильтрами.
- `product.html?item=<slug>` — карточка и прайс выбранного товара.
- `faq.html` — вопросы и ответы.
- `js/products-data.js` — единственный источник данных каталога и цен.
- `js/config.js` — Telegram-ссылки и общие параметры сервиса.
- `css/` — общие и постраничные стили.

## Обновление каталога

Добавляйте и редактируйте товары только в `js/products-data.js`. Поле `slug` используется в URL, `filters` определяет категории каталога, а `prices` наполняет прайс на странице товара.

Доступные фильтры: `games`, `subs`, `cards`, `topup`. Один товар может входить в несколько фильтров.

## Проверка

```bash
for file in js/*.js; do node --check "$file"; done
git diff --check
```

Перед публикацией проверьте главную, фильтры каталога, поиск, выбор цены и FAQ на широком и мобильном экране.
